# Build and validate Blitz pack 1.2.0

Use Node.js 20+, Python 3, and Windows. Generation and the checksum checker use standard libraries only. The native test certificate helper uses PowerShell 7/.NET. No Blitz binaries or generated private certificate keys are included.

From the source package root, generate from the exact original 3.0.17 pair:

```powershell
node .\source\blitz\build-pack.cjs 'C:\Original\Blitz\resources\app.asar' .\Blitz-3.0.17.patchwork.json 'C:\Original\Blitz\icudtl.dat'
```

The generator pins both original hashes. It keeps the published bundle ID for catalog replacement. The old target version in that ID is a historical identifier, not a compatibility declaration.

## Current production engine

Copy your installed Patchwork 1.1.1 `Patchwork.exe` and `Mono.Cecil.dll` into a fresh runner directory. Compile `source/blitz/ValidateProductionPack.cs` with the Windows Framework 4 compiler, referencing that copied `Patchwork.exe`, `System.Core.dll` and `System.Web.Extensions.dll`. Place the resulting executable beside the copied assemblies.

```powershell
& 'C:\Runner\ValidateProductionPack.exe' .\Blitz-3.0.17.patchwork.json 'C:\Original\Blitz\resources\app.asar' 'C:\Original\Blitz\icudtl.dat' 'C:\FreshScratch'
python .\source\blitz\check-checksums.py 'C:\FreshScratch\staged-pairs' 'C:\Original\Blitz\icudtl.dat'
node .\source\blitz\test-telemetry.cjs 'C:\FreshScratch\staged-pairs\clean-desktop+compact-window+remove-telemetry.asar'
node .\source\blitz\test-updates.cjs 'C:\FreshScratch\staged-pairs\clean-desktop+compact-window+remove-telemetry.asar'
```

The runner refuses an existing scratch directory and uses copied targets/private history. It tests all seven selections, deterministic replays, deselection/reselection and byte-exact restoration, then rehashes the supplied original files. Its result JSON and staged pairs are private evidence; do not distribute copied Blitz binaries.

## Rollback and hook fixtures

The existing `ValidatePack.cs` runner needs a Patchwork test build exposing `BeforeWriteForTest`; it was exercised with the retained 0.8.2 test engine. Compile it beside that engine and pass `PACK_JSON ORIGINAL_ASAR NEW_SCRATCH ORIGINAL_ICU`. Its historical `both.asar` filename now means all selected patches. It also writes `clean.asar` and `compact.asar`.

```powershell
node .\source\blitz\test-runtime.cjs 'C:\RollbackScratch\artifacts' 'C:\Original\Blitz\resources\app.asar' --node-only
```

Omitting `--node-only` also runs the optional Playwright layout fixtures; provide the existing module/browser through `PATCHWORK_PLAYWRIGHT_MODULE` and `PATCHWORK_CHROMIUM_EXECUTABLE` if available. The native Chromium fixture below checks layout without those optional dependencies.

## Private native Electron fixture

Copy Blitz's top-level Electron runtime files and `locales` to a new workspace directory. Do not copy its original `resources/app.asar` or app profile. Create `resources/app/package.json` with a `main` value of `test-electron.cjs`. Copy the current `test-electron.cjs` and `desktop-cleanup.js` there. Extract `src/electronWindowHandlers.js` from the staged all-selected ASAR as `resources/app/electronWindowHandlers.js` using `asar-reader.cjs`.

Generate the ephemeral certificate in that fixture app folder:

```powershell
pwsh -File .\source\blitz\generate-fixture-cert.ps1 'C:\Fixture\resources\app'
```

Start the copied executable with `--disable-gpu --disable-software-rasterizer --result=ABSOLUTE_WORKSPACE_RESULT_JSON`. For PowerShell `Start-Process`, use `-WindowStyle Hidden`. It uses hidden windows, a profile beside the result, hostnames mapped to loopback, and exact-certificate trust restricted to the private test session. It self-exits within 60 seconds. All fixture requests are local; no account or public service is used. Generated keys and profiles must stay out of source/release packages.

See `docs/blitz/3.0.17-VALIDATION.md` and the included result records for the performed checks and remaining live-test limits.
