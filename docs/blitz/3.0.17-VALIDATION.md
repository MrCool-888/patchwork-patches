## Frontend evidence

Downloaded the versioned public frontend and its 1,295 referenced JavaScript/CSS assets, 6,039,607 bytes total, for inert source inspection. The same scoped selectors and ad loaders are present in this frontend:

- [Ad loaders](https://blitz-desktop.blitz.gg/3.0.17/_app/immutable/chunks/BtPG_IYA2.js): verified CloudFront `prebid-load.js` and Primis video loader.
- [Leaderboard promotion](https://blitz-desktop.blitz.gg/3.0.17/_app/immutable/chunks/Cg0Q9rDE.js) and [its CSS](https://blitz-desktop.blitz.gg/3.0.17/_app/immutable/assets/LeaderboardButton.m0pcM7c6.css): `leaderboard-promo.svelte-x9c7ob` and ad/promotion containers.
- [Premium banners](https://blitz-desktop.blitz.gg/3.0.17/_app/immutable/chunks/DNNJbc052.js): existing scoped latest-feature and Blitz3 promotion rules.
- [Science sender](https://blitz-desktop.blitz.gg/3.0.17/_app/immutable/chunks/DwiDBGO3.js), [service constants](https://blitz-desktop.blitz.gg/3.0.17/_app/immutable/chunks/cXpETud6.js), and [science initialization](https://blitz-desktop.blitz.gg/3.0.17/_app/immutable/chunks/pD4bQ_9S2.js): batched usage/error events go to `science.v2.iesdev.com/append`; setup collects machine identity/specs and polls open windows for usage reporting.
- [Root frontend](https://blitz-desktop.blitz.gg/3.0.17/_app/immutable/nodes/0.7_WS4JSa.js): loads Google's `gtag/js` analytics script.

The privacy option adds cancellation inside the existing `onBeforeSendHeaders` callback, shared by desktop and overlay setup. It does not replace the ad hook's `onBeforeRequest` listener or the original request-header/CORS handling. It blocks the Science host, Google Analytics host family, exact Google `gtag/js` path, and exact machine-segmentation path. The native-side segmentation function is also replaced, covering its Node fetch.

Crash-handler module replacement preserves its exported async setup function while starting neither Electron's uploader nor the custom native handler. Hardware-info IPC returns null; open-window analytics IPC returns an empty array. Existing functional machine ID, process/game APIs and game heartbeats are preserved. In particular, a Deadlock heartbeat also populates the profile UI, so its name/comment alone was not treated as grounds for removal.

- Compatibility/rollback runner: Patchwork 0.8.2 test engine passed real-size archive/companion preview, option updates, an injected second-file write failure with restoration of both prior files, worker transactions, stale-preview rejection, and exact restore.
- Archive/code: all **3,061 entries** preserved; unrelated content and metadata unchanged for checked outputs; edited member integrity and JavaScript syntax valid. Compact behavior passed nine account-label/screen-size fixtures. Hook tests passed exact version/domain/overlay exclusions, reload, SPA navigation, recreation and a single session listener.

Seven verified destination examples cancelled, ten functional/API examples retained, and LCU authentication, Blitz headers and CORS handling preserved. Crash, hardware, segmentation and open-window collector tests performed no collection. This is controlled execution, not remote service observation.
- Update behavior: actual patched updater functions suppress automatic client/frontend startup and polling checks by default; manual calls and explicit opt-in work.
- Independent Python XXH32 implementation passed reference vectors. All seven staged ASAR/companion pairs have matching footers, with every preceding companion byte unchanged. See the included checksum results.
- Native Electron HTTPS fixture: exact copied installed executable, private profile, generated one-day certificate trusted only by the fixture's private session, test hostnames mapped to loopback. **10 ad requests and 28 telemetry requests cancelled; one ad listener registration; 31 response-handler calls retained.** Telemetry fixture endpoints succeeded before installing the privacy handler and failed afterward. Cleanup-independent views also retained telemetry blocking. Warm cache, reload, SPA/full navigation, unknown-frontend fallback, view recreation, dynamic slots, 800/1500px banner/container collapse and native 940 × 500 window minimum passed.

The first native fixture attempts exposed a fixture certificate-trust issue on its initial cross-origin API request before any patch was installed. Adding exact-certificate handling scoped to the private fixture session resolved it; the final run passed. The separate Playwright layout runner was unavailable because its optional dependency is absent; the bundled native Chromium fixture performed layout checks instead. A Python native xxhash wheel retained from earlier work targeted Python 3.12, so the independent standard-library checker was used with current Python 3.14.
